# MirrorCheck v0.13 — revised three-minute demo script

This is the script for the next recording. The existing published MP4 records v0.12 and has not been replaced by this text. Use fictional accounts and verified live responses. Do not show moderator codes or private appeal credentials. Do not narrate a request as successful until its actual response is visible.

| Time | Screen | English narration |
| --- | --- | --- |
| 0:00–0:20 | Animated MirrorCheck landing, then the fictional profile | “A copied profile can look convincing before anyone checks it. MirrorCheck turns a second look into evidence, with AI that helps and a human who decides. This is an unofficial Instagram-style prototype using fictional accounts.” |
| 0:20–0:45 | Report account, choose impersonation, upload two screenshots | “The reporter starts from the profile and attaches screenshots of the original and suspected copy. PaddleOCR reads editable profile details. The reporter checks them before submitting. Matching photos are evidence of reuse, not proof of identity.” |
| 0:45–1:05 | Processed preview, two opaque contact masks | “Email and phone lines are covered locally using Presidio before Meta receives images. The preview and saved reviewer evidence use the processed bytes. If preparation fails, the external request stops.” |
| 1:05–1:30 | Actual Meta and independent ML response | “Meta Muse Spark returns similarities, differences and limitations. Separate local models add text-reuse and spam-pattern signals. Avatar presence is excluded from the profile model. These scores describe evidence; the report is still under review.” |
| 1:30–1:50 | Moderator enters a reason, confirms; profile warning appears | “A moderator reviews the evidence, writes an explanation and explicitly saves the decision. A version check prevents an outdated review from replacing a newer one. The confirmed warning appears in the profile and survives a reload.” |
| 1:50–2:15 | Private appeal form, pending appeal, moderator reason and overturn | “New context can change the decision. A private, expiring link opens only this report. Submitting an appeal keeps the warning until review. The moderator can uphold or overturn it with another explanation, and the history records both decisions. For this fictional example, assume permission to mirror the portfolio is verified outside the prototype.” |
| 2:15–2:45 | `/benchmark.html`, test counts and limitations | “On controlled external-text test pairs, recall improved from sixty-two to ninety-two percent, with zero observed false positives in one hundred negatives. On strongly transformed Copydays photo regions, recall improved from two to thirty-six percent. Many difficult copies are still missed. These are research challenges, not real Instagram accuracy claims.” |
| 2:45–3:00 | Decision history, profile without warning, landing | “MirrorCheck brings privacy, independent signals, explained decisions and a way to challenge mistakes into the same workflow. Public-demo deployment is prepared; hosting is still pending. AI assembles evidence. A human remains accountable.” |

For a live presentation, use the actual decision outcome and numbers shown. Do not invent ownership verification, a public URL or benchmark Meta coverage. The full external corpus has not been run through Meta. The measured model improvements and the live Meta demonstration are separate evidence.
